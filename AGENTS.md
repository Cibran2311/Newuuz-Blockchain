# Project Instructions

This repository contains a MkDocs Material course site for CS422/CS423 Blockchain Technologies.

## Audience

Write for beginner students. They may be new to blockchain, MetaMask, Solidity, Polkadot, TON, faucets, explorers, transaction hashes, and smart contract events.

## Lab Style

Every lab must be self-contained and include:

- Goal
- Why This Lab Matters
- What You Will Learn
- Required Reading
- Required Software
- Key Terms
- Safety Notes
- Step-by-Step Instructions
- Expected Result
- Submission
- Automatic Validation
- Common Mistakes
- Self-Check Questions

## Safety

Never include private keys, seed phrases, API keys, or real credentials.
Use testnets only: Ethereum Sepolia, Polkadot Westend / AssetHub test environments, and TON Testnet.

## Build Check

After changes, run:

```bash
mkdocs build --strict
```
