# CS422/CS423 Blockchain Technologies

Student-ready MkDocs Material course site for the Blockchain Technologies course.

## Required Course Path

```text
Lab 1, Lab 2, Lab 3,
Lab 4, Lab 5, Lab 6,
Lab 8, Lab 10,
Assignment 3,
Assignment 4
```

## Additional Challenges

```text
Lab 7, Lab 9, Lab 11, Lab 12,
NFT Quest,
Security Arena
```

## Expected Workload

| Level | Approximate Workload |
|---|---:|
| Required path | 40–55 hours |
| Required path + challenges | 55–75 hours |
| Advanced path | 85+ hours |

## Local Preview

```bash
python -m pip install -r requirements.txt
mkdocs serve
```

Open:

```text
http://127.0.0.1:8000
```

## Build

```bash
mkdocs build --strict
```

## GitHub Pages

1. Push the repository to GitHub.
2. Open **Settings → Pages**.
3. Select **Source → GitHub Actions**.
4. Run **Actions → Deploy MkDocs**.
