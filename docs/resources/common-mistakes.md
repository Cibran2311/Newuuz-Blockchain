# Common Mistakes

## General

- submitting a repository or explorer link that the instructor cannot open;
- using wrong network;
- submitting someone else's transaction;
- losing seed phrase;
- uploading private key.

## Ethereum

- using Mainnet instead of Sepolia;
- confusing ETH transfer and ERC20 transfer;
- submitting contract address instead of transaction hash.

## Polkadot

- confusing account address and extrinsic hash;
- using wrong chain.

## TON

- using mainnet instead of testnet;
- confusing wallet address and jetton wallet address;
- submitting account page instead of transaction trace.
