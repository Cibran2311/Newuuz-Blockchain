# How to Study

## Recommended workflow for every lab

1. Read the goal.
2. Open the required links.
3. Prepare the software.
4. Complete tasks step by step.
5. Save all transaction hashes.
6. Push code and reports to the assigned GitHub repository.
7. Update the matching section in `submission.json`, mark it `submitted`, and push the commit.
8. Click **Turn in** and wait for instructor feedback.

## What to save

Always save:

- wallet address;
- transaction hash;
- contract address;
- explorer URL;
- short explanation.

## Never submit

Never submit:

- seed phrase;
- private key;
- MetaMask password;
- real mainnet funds;
- API keys.
