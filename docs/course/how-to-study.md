# How to Study

## Recommended workflow for every lab

1. Read the goal.
2. Open the required links.
3. Prepare the software.
4. Complete tasks step by step.
5. Save all transaction hashes.
6. Fill `submission.json`.
7. Push to GitHub Classroom.
8. Check GitHub Actions result.

## What to save

Always save:

- wallet address;
- transaction hash;
- contract address;
- explorer URL;
- short explanation.

## Never submit

Never submit:

- seed phrase;
- private key;
- MetaMask password;
- real mainnet funds;
- API keys.
