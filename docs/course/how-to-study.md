# How to Study This Course

## Recommended workflow

For each lab:

1. Read the introduction.
2. Open the required documentation from the **References** section.
3. Complete the practical steps.
4. Save transaction hashes and explorer links.
5. Add evidence to `submission.json`.
6. Push to GitHub Classroom repository.
7. Check GitHub Actions result.

## What to save every time

- wallet address;
- transaction hash;
- contract address if deployed;
- explorer link;
- short explanation;
- screenshots only if explicitly required.

## Do not submit

- private keys;
- seed phrases;
- API keys;
- mainnet funds or mainnet transactions unless explicitly requested.
