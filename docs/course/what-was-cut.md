# What Was Cut

This course version is reduced on purpose.

The full version had too many heavy tasks for average students. This version keeps the core learning outcomes and moves risky tasks to optional/advanced status.

## Removed From Required Path

| Item | New Status | Reason |
|---|---|---|
| Lab 7 — DEX arbitrage | Optional / bonus | Useful but combines DeFi math, liquidity, swaps, and contract logic |
| Lab 9 — AssetHub / XCM | Optional / demo | XCM is conceptually and technically heavy |
| Lab 11 — Jetton transfer | Optional / guided report | Good TON topic, but not required for minimum course logic |
| Lab 12 — TON DeFi / Security | Advanced bonus | Too complex and potentially unstable for default path |
| Assignment 1 — NFT Quest | Optional / Lab 6 extension | Overlaps with Lab 6 NFT ownership and approvals |
| Assignment 2 — Ethernaut | Optional security track | Time cost is unpredictable |

## What Stayed Required

| Item | Why It Stayed |
|---|---|
| Lab 1 | Students need wallet and testnet basics |
| Lab 2 | Hashes are foundational |
| Lab 3 | Blocks, Merkle trees, and mining explain blockchain structure |
| Lab 4 | Students must read transactions and gas |
| Lab 5 | ERC20 is a core Web3 primitive |
| Lab 6 | NFTs teach ownership, approvals, token IDs |
| Lab 8 | Polkadot gives non-EVM perspective |
| Lab 10 | TON gives asynchronous blockchain perspective |
| Assignment 3 | Group chain creates real interaction and team workflow |
| Assignment 4 | Students must explain what they did technically |

## If the Course Is Still Too Heavy

Cut in this order:

1. Make Assignment 4 shorter.
2. Reduce Lab 3 mining difficulty.
3. Make Lab 8 a guided explorer-only task.
4. Make Lab 10 a guided explorer-only task.
5. Reduce Assignment 3 group report length.
