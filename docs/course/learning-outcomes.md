# Learning Outcomes

After completing the course, students will be able to:

- explain blockchain fundamentals;
- use wallets and explorers;
- understand hash functions and Merkle trees;
- explain PoW, PoS, and NPoS;
- interact with Ethereum smart contracts;
- work with ERC20 and NFT standards;
- understand AMM and DeFi mechanics;
- solve basic smart contract security challenges;
- execute transactions on Polkadot and TON;
- compare Ethereum, Polkadot, and TON architectures.
