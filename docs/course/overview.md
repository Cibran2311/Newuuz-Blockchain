# Course Overview

This course introduces blockchain technologies through practical work.

The main focus is not theory alone. The main focus is the ability to perform blockchain actions, verify them, and explain them clearly.

## Course Goals

By the end of the course, students should be able to:

- use blockchain wallets safely;
- send and inspect testnet transactions;
- understand hash functions, blocks, and Merkle trees;
- read Ethereum transactions and gas data;
- interact with ERC20 and ERC721 contracts;
- compare Ethereum, Polkadot, and TON at a basic architectural level;
- work in a group on a shared smart contract workflow;
- prepare evidence-based blockchain reports.

## Required Labs

| Lab | Topic | Main Output |
|---|---|---|
| Lab 1 | Wallet and first transaction | Sepolia transaction hash |
| Lab 2 | Hashing | Collision evidence and explanation |
| Lab 3 | Blocks and Merkle trees | Simple block/mining output |
| Lab 4 | Ethereum transactions | Gas and transaction analysis |
| Lab 5 | ERC20 token | Token evidence and transfers |
| Lab 6 | NFT ownership | NFT address, token ID, approval/transfer evidence |
| Lab 7 | DEX / AMM arbitrage | Swap transactions and portfolio calculation |
| Lab 8 | Polkadot basics | Polkadot account and extrinsic evidence |
| Lab 9 | AssetHub / XCM | Cross-chain extrinsic and route explanation |
| Lab 10 | TON basics | TON testnet transaction evidence |
| Lab 11 | TON jettons | Jetton contract and message analysis |
| Lab 12 | TON DeFi / security | Swap or security challenge evidence |
