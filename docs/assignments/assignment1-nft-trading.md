# Assignment 1 — NFT Trading and Smart Contract Interaction

## Goal

Work with NFT ownership, approvals, and special smart contract interaction.

## Learning Objectives

After completing this assignment students will be able to:

- interact with smart contracts;
- analyze blockchain events;
- collect evidence from explorers;
- submit machine-readable results.

## Tasks

1. Receive or buy professor NFT
2. Transfer or sell professor NFT back
3. Mint personal NFT
4. Approve special contract
5. Transfer personal NFT to special contract
6. Submit evidence

## Deliverables

Students must submit all evidence in `submission.json` and include required reports, links, or scripts in the repository.

## submission.json Example

```json
{
  "assignments": {"assignment1": {"professor_nft_contract": "0x...", "professor_token_id": "1", "personal_nft_contract": "0x...", "special_contract": "0x...", "tx_hashes": ["0x..."]}}
}
```

## Automatic Validation

The checker verifies submitted blockchain evidence, correct network, wallet ownership, and assignment-specific conditions.
