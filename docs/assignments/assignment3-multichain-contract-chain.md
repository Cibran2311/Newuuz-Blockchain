# Assignment 3 — Multi-chain Contract Chain

## Goal
Perform similar blockchain actions in Ethereum, Polkadot, and TON and compare architectural differences.

## Tasks
1. Start the chain on Ethereum Sepolia by interacting with the assigned contract.
2. Continue in Polkadot using AssetHub/XCM or an assigned extrinsic.
3. Complete the final step in TON Testnet.
4. Compare fee model, speed, explorer UX, account model, contract model, and tooling.

## Automatic validation
The checker verifies Ethereum transaction/event, Polkadot extrinsic, TON transaction/message trace, and linked student identity.
