# Assignment 2 — Smart Contract Security Challenges

## Goal

Solve Ethernaut levels and reach complexity score ≥ 10.

## Recommended documentation

- Ethernaut, Solidity docs, Etherscan.

## Learning Objectives

Students will learn to:

- interact with smart contracts;
- analyze blockchain systems;
- compare blockchain ecosystems;
- work with blockchain explorers and events.

## Tasks

1. Complete required blockchain workflow.
2. Record blockchain evidence.
3. Analyze results.
4. Submit deliverables.

## Deliverables

Students must submit:

- wallet addresses;
- transaction hashes;
- explorer links;
- assignment-specific evidence.

## Automatic Validation

The checker verifies:

- blockchain events;
- correct networks;
- successful interactions;
- assignment completion.
