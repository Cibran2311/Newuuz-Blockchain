# Assignment 2 — Ethernaut

## Goal
Solve Ethernaut smart contract security levels and reach a total complexity score of at least 10.

## Tasks
1. Open Ethernaut.
2. Connect the same Ethereum Sepolia wallet used for the course.
3. Create level instances.
4. Exploit vulnerabilities.
5. Submit level instances.
6. Reach total complexity score ≥ 10.

## Automatic validation
The checker verifies `LevelCompletedLog` events, unique completed levels, complexity score, and wallet ownership.
