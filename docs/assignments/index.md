# Assignments

The course currently keeps all four assignments in the main block.

## Required Assignments

| Assignment | Purpose | Main Evidence |
|---|---|---|
| Assignment 1 — NFT Quest | Complete an NFT ownership and contract-transfer flow | Contract addresses, token IDs, transaction hashes |
| Assignment 2 — Security Arena | Complete Ethernaut levels on Sepolia | Registered-wallet completion events and write-ups |
| Assignment 3 — Group Chain of Contracts | Build a group-owned Sepolia smart contract chain | Contract addresses, transaction hashes, events, group report |
| Assignment 4 — Web3 Technical Article | Explain a blockchain topic using course evidence | Article text, links, screenshots, technical explanation |

## Why Assignment 3 Is Central

Assignment 3 combines:

- Ethereum;
- smart contracts;
- group coordination;
- deployment;
- contract-to-contract interaction;
- event verification;
- evidence indexed through `submission.json`;
- Etherscan checking.

It is the main practical checkpoint of the course.

## Submission

All four assignments remain in the main course block. Each student reports them in the matching `assignments.assignment1`–`assignments.assignment4` section of `submission.json`. Assignment 3 also uses a shared group report, while every member records an individual contribution in their own JSON file.

!!! warning
    Do not submit private keys, seed phrases, or mainnet transactions.
