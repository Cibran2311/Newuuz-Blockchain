# Section 3 — Alternative Blockchain Ecosystems

This compact section introduces two non-Ethereum ecosystems:

- Polkadot;
- TON.

The goal is not to make students experts in both ecosystems. The goal is to show that blockchain architectures can be different.

## Required Labs

| Lab | Purpose |
|---|---|
| Lab 8 — Enter Polkadot | Create or use a Polkadot-style account, submit an extrinsic, inspect it |
| Lab 10 — Enter TON | Use TON testnet, submit a transaction, inspect it |

## Optional Extensions

| Optional Lab | Purpose |
|---|---|
| Lab 9 — AssetHub / XCM | Cross-chain message concepts |
| Lab 11 — Jetton Transfer | TON token transfer analysis |
| Lab 12 — TON DeFi / Security | Advanced TON practical task |
