# Section 3 — Alternative Blockchain Ecosystems

This section introduces two non-Ethereum ecosystems:

- Polkadot;
- TON.

The goal is not to become an expert in both ecosystems immediately. The goal is to see that blockchain systems can use different account models, transaction formats, execution models, and explorers.

## Required Labs

| Lab | Purpose |
|---|---|
| Lab 8 — Enter Polkadot | Create or use a Polkadot-style account, submit an extrinsic, inspect it |
| Lab 10 — Enter TON | Use TON testnet, submit a transaction, inspect it |

## Learning Focus

After this section, students should be able to explain:

- how Ethereum account and transaction experience differs from Polkadot;
- how TON uses an asynchronous message-based model;
- how explorers are used to prove blockchain activity;
- why multi-chain systems are harder than single-chain systems.
