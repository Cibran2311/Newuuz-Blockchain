# Lab 10 — HackTON

## Goal

Complete the first HackTON CTF level in class and learn the TON security workflow.

## Platform

- https://www.hacktheton.com/en/level/introduction

## Tasks

1. Open HackTON.
2. Connect a TON testnet wallet.
3. Read the vulnerable contract/task description.
4. Perform the required transaction or exploit.
5. Verify the result on Tonviewer.

## Deliverable

Submit the level result and the relevant transaction link.
