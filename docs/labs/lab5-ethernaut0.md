# Lab 5 — Ethernaut 0

## Goal

Complete Ethernaut Level 0 in class and understand the Ethernaut workflow.

## Platform

- https://ethernaut.openzeppelin.com/

## Workflow

1. Connect MetaMask on Sepolia.
2. Open Level 0.
3. Create a level instance.
4. Interact with the contract according to the instructions.
5. Submit the instance.
6. Verify completion on Etherscan.

## Deliverable

Submit the transaction links for instance creation, interaction, and submission.
