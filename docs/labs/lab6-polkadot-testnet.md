# Lab 6 — Polkadot Testnet Transaction

## Goal

Set up a Polkadot.js wallet and send a transaction on the Westend testnet.

## Tools

- https://polkadot.js.org/extension/
- https://polkadot.js.org/apps/
- https://faucet.polkadot.io/westend
- https://westend.subscan.io/

## Tasks

1. Install Polkadot.js extension.
2. Create or import an account.
3. Switch to Westend.
4. Obtain test WND from the faucet.
5. Send a transaction to the instructor address.
6. Verify the transaction on Subscan.

## Deliverable

Subscan transaction link.
