# Additional Challenges

Additional challenges are designed for students who want to go deeper.

They can be used for:

- bonus points;
- stronger portfolio artifacts;
- individual project work;
- makeup work;
- final presentation topics.

## Challenge List

| Challenge | Best For | Main Skill |
|---|---|---|
| Lab 7 — Trade Like a DeFi Bot | DeFi-interested students | AMM mechanics and arbitrage reasoning |
| Lab 9 — Send a Cross-chain Message | Polkadot-interested students | AssetHub and XCM basics |
| Lab 11 — Dissect a Jetton Transfer | TON-interested students | TON token/message analysis |
| Lab 12 — Trade or Break on TON | Advanced TON work | TON DeFi or security |
| NFT Quest | NFT-interested students | Extended NFT ownership workflow |
| Security Arena | Security-interested students | Ethernaut smart contract vulnerabilities |

## Recommended Rule

Choose one challenge if you want extra points.

Choose two or more challenges only if you are comfortable with the required course path.
