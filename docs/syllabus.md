# Syllabus

## Quarter structure

| Quarter | Focus | Core idea |
|---|---|---|
| Q1 | Blockchain fundamentals and cryptography | Hash functions, Merkle trees, consensus, PoW difficulty |
| Q2 | Ethereum | Transactions, gas, ERC20, Disperse, NFTs, DEX, contract chain |
| Q3 | Polkadot | Similar practical actions in a different architecture: accounts, extrinsics, AssetHub, XCM |
| Q4 | TON | Similar practical actions in an async, sharded, message-based architecture |

## Methodological idea

Students perform similar actions in several blockchain ecosystems and compare account model, transaction model, fee model, smart contract model, explorer tooling, finality, speed, and developer experience.
