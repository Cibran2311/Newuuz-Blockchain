# submission.json

All assignments use a common submission format.

## Example

```json
{
  "student": {
    "full_name": "Student Name",
    "student_id": "123456"
  },
  "wallets": {
    "ethereum": "0x...",
    "polkadot": "5...",
    "ton": "kQ..."
  },
  "labs": {},
  "assignments": {}
}
```

## Rules

- Never submit private keys.
- Never submit seed phrases.
- Use testnet addresses.
- Make sure JSON is valid.
