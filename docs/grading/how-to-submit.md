# How to Submit

All work is submitted through the assignment created in Google Classroom. GitHub stores code, notebooks, reports, and the student repository used for review. There is no student submission JSON file.

## Before the first submission

Confirm with the instructor that the protected course registry contains your current:

- student ID and Classroom email;
- GitHub profile or repository;
- Sepolia wallet;
- Polkadot and TON testnet wallets when a task uses them.

Only activity from registered addresses can be matched automatically.

## Canonical Submission Workflow

1. Open the assignment in Google Classroom.
2. Read the lab or assignment validation mode: automatic, semi-automatic, or manual.
3. Complete the work on the required testnet or in the local notebook/script.
4. Push code, notebooks, reports, and README evidence to the assigned student GitHub repository.
5. Attach or paste the repository, notebook, explorer, or article link requested by the task.
6. Add a short note if a transaction used a newly registered wallet.
7. Click **Turn in**.

For Lab 2 and Lab 3, submit the student repository or notebook link through Google Classroom. Do not commit to the course repository.

## What Is Checked Automatically

The current production GitHub Actions checker covers:

- Assignment 1: Token + Swap + NFT mint;
- Assignment 2: Ethernaut completion and configured complexity.

The remaining laboratory evidence, explanations, group contributions, and article quality are reviewed manually until their checks are added to the workflow.

## If the result needs review

The instructor checks the Manual review and Errors worksheets. Common reasons are:

- the wallet or GitHub repository is not registered;
- the wrong testnet was used;
- an explorer or RPC service was temporarily unavailable;
- the evidence is qualitative and cannot be graded safely by a script;
- the transaction has not been indexed yet;
- the repository or report does not contain the required evidence.

!!! danger
    Never submit a seed phrase, private key, wallet password, API key, or student JSON file through Classroom, GitHub, or Google Sheets.
