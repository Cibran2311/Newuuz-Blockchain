# Auto-check System

The course uses automatic blockchain validation.

## Checker verifies

- transaction existence;
- smart contract events;
- correct wallet ownership;
- successful execution;
- correct blockchain network.

## Main validation sources

- Etherscan / Ethereum RPC;
- Subscan / Polkadot RPC;
- Tonviewer / TON Center API;
- GitHub repository files;
- `submission.json`.
