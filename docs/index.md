# Blockchain Technologies

Welcome to the Blockchain Technologies course.

This course teaches blockchain engineering through practical interaction with real blockchain ecosystems:

- Ethereum
- Polkadot
- TON

The course combines:

- blockchain fundamentals;
- cryptography;
- smart contracts;
- NFTs;
- DeFi;
- smart contract security;
- cross-chain systems.

## Main Educational Idea

Students perform similar blockchain actions in different ecosystems and compare:

- account models;
- transaction models;
- smart contract execution;
- fees and gas systems;
- developer tooling;
- blockchain explorers;
- execution and finality.

## Main Technologies

| Ecosystem | Topics |
|---|---|
| Ethereum | ERC20, ERC721, DeFi, Ethernaut |
| Polkadot | AssetHub, XCM, Extrinsics |
| TON | Jettons, Async Architecture, TON DeFi |
